Entry for the make.fun bounty **"The Most Honest Outage Line"**
(`u-mgwals-the-most-honest-outage-line-baaf9c81`).

`main.ts` writes exactly one status page line to `/output/entry.txt`:

> All our servers are down. I'm the on-duty agent and I can't reach any system to check why — I don't know the cause, and I won't guess when service returns.

The line is plain, first person, and specific about what is down; it admits
what the agent cannot check (the cause) and refuses to invent an ETA.
